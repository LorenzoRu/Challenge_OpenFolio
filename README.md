# Challenge OpenFolio

## 1 : Le contexte

L'idée de ce challenge vient d'un besoin de refaire un portfolio. Mon besoin était d'avoir un CMS pensé pour être déployé facilement et offrant un minimum de sécurité (séparer la base de données du site via des conteneurs Docker).

## 2 : Les règles

- 4h pour réaliser un CMS fonctionnel
- Utilisation d'outils d'IA autorisée dans la réalisation

## 3 : La stack

- Golang
- HTML/CSS/JS
- Docker
- Postgres

## 4 : Les outils

- Figma
- OpenCode
- VS Code

## 5 : Le cahier des charges

- Page de connexion : fonctionnelle
- Dashboard : fonctionnel
- Éditeur de page : presque terminé

## 6 : Mon retour

4h, c'est vraiment court ! Le résultat est fonctionnel sur pratiquement la totalité du cahier des charges. Il manque toutefois une partie importante concernant l'interaction. Le design est propre, mais on sent le côté « effet template » apporté par une IA que je n'estime pas avoir assez cadrée pour la réalisation.
